# Tokens

Расширение VS Code для тех, кто работает с Claude Code и Codex: сколько осталось лимитов, куда ушли токены, какие чаты открыты, на какой стадии проекты.

**Установка:** [INSTALL.md](INSTALL.md). Там есть готовый промт: вставьте его в чат Claude или Codex, и агент поставит расширение сам.

## Что показывает

- **Строка состояния:** `Claude 41% · 38%` и `Codex 0% · 96%` — окно 5 часов и неделя. При 80% фон становится жёлтым, при 95% красным. Клик открывает дашборд.
- **Дашборд:**
  - **Циферблат на каждого агента.** Внутреннее кольцо — 5 часов, внешнее — неделя. Дуга — сколько израсходовано, точка — сколько прошло времени окна. Если дуга обогнала точку, лимит тратится быстрее времени. При наведении на кольцо появляются подробности.
  - **Открытые чаты.** Видно, какие работают прямо сейчас. Клик переводит в чат, есть кнопка «Остановить все чаты».
  - **Расход токенов** по дням и по проектам.
  - **Проекты:** стадия и текущая задача из `STATUS.md`, git. Клик раскрывает все чаты проекта, последний подсвечен.
- **Боковая панель Tokens:** маленькие циферблаты, сроки сброса, темп.
- **Уведомления**, когда лимит переходит 80% и 95%, и когда окно сбросилось.

## Настройки

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| `tokens.projectsRoot` | открытая папка | Папка с проектами. Если в ней есть `projects.code-workspace`, проекты берутся из него |
| `tokens.warnPercent` | 80 | С какого процента лимит считается «мало» |
| `tokens.criticalPercent` | 95 | С какого процента лимит «почти исчерпан» |
| `tokens.notifications` | вкл | Уведомления о порогах |
| `tokens.claudeRefreshMinutes` | 5 | Как часто обновлять лимиты Claude; 0 — выключено |

## Разработка

- **Расширение** — чистый JavaScript (`extension.js`, `src/`).
- **Интерфейс** — React + Motion в `webview/`, собирается в `media/webview.js` командой `npm run build`.
- **Самопроверка:** `node test/selftest.js`.
- **Сборка и установка `.vsix`:** `scripts/package.ps1 -Install`.
